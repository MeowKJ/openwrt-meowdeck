# Contributing

MeowDeck uses short branches and focused pull requests.

1. Open or choose an issue.
2. Create a branch such as `feat/service-groups` or `fix/tcp-timeout`.
3. Use Conventional Commit messages (`feat:`, `fix:`, `docs:`, `ci:`).
4. Run `make check`, `make test`, and `make build`.
5. Open a pull request and keep its scope bounded.

Node.js 22+, npm, and Go 1.23+ are required for development. OpenWrt is only
required for deployment testing.
